# Controlled exposure and learning protocol

**Stage:** public preview, not a live paid product. **Cost policy:** no paid advertising, no paid services, no spending before verified first $1 revenue.

## Testable hypotheses
1. **Comprehension:** visitors understand what a CSV file is and what is included.
2. **Usability:** a visitor can download, open, and edit the template without assistance.
3. **Value proposition:** visitors can explain why they would or would not pay $1 for an enhanced version.
4. **Acquisition:** discover a lawful, opt-in channel where people interested in cash-flow tracking may find the page.

## Privacy-preserving measurement
- No analytics SDK, tracking pixel, cookies, or personal-data collection.
- Accept optional qualitative feedback through public GitHub issues. Contributors must avoid personal and financial data. Issues are public.
- Do **not** count GitHub stars, page visits, file downloads, fictional personas, or expressed interest as paid purchases.
- Record only aggregate observations supported by a link to the public feedback item, never invent responses.

## Publication gates
- Verify GitHub Actions workflow success and that the public URL actually serves the latest `index.html`.
- Inspect rendered page on mobile, check download links and GitHub feedback link.
- Do not initiate unsolicited outreach, spam, paid ads, or misleading endorsements.
- Keep the checkout disabled until a payment provider and fulfillment flow are genuinely verified.
- If the deployment workflow fails because Pages is not configured, check Settings → Pages → Build and deployment → GitHub Actions.

## Success criteria
First $1 of **verified real income** received, with zero pre-income spending, and a repeatable lawful acquisition and fulfillment process. Synthetic results remain separate.
