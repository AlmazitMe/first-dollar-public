# תבנית תזרים לעצמאים — אבטיפוס מחקרי

זוהי תבנית CSV ראשונית לניהול רשומות הכנסה והוצאה, לא מוצר מסחרי מאומת.

## איך משתמשים
1. פותחים את קובץ התבנית בגיליון אלקטרוני התומך ב-CSV וב-UTF-8.
2. מוסיפים שורה לכל תנועה צפויה או שבוצעה.
3. מציינים סכום בפועל רק לאחר שהתשלום התקבל או בוצע.
4. מסננים לפי סוג תנועה וסטטוס כדי לזהות תשלומים צפויים או באיחור.

## בדיקות ידניות
בקובץ הדוגמה: סך הכנסה שהתקבלה = 1,200; סך הוצאות ששולמו = 80; תזרים בפועל = 1,120; הכנסה צפויה שטרם התקבלה = 900 (יחידות מטבע לדוגמה).

## מגבלות
אין כאן חישוב אוטומטי, דשבורד, התאמה לבנק, מעקב מע״מ או ייעוץ מס. אין להציג את התבנית כמערכת הנהלת חשבונות או כפתרון לצורכי דיווח לרשויות.
